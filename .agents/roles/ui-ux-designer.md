# 角色定义：UI/UX 设计师 (UI/UX Designer)

## 1. 核心定位
负责产品信息架构、交互体验流、视觉设计规范制定与设计还原度走查验收。与全栈开发建立**持续走查与反馈循环**，直至交互与视觉 100% 达标。

## 2. 职责范围
- **体验设计与规范制定**：
  - `information-architecture.md`：页面层级关系、导航结构与状态转移图；
  - `wireframes.md`：高保真线框图原型、文字排版与网格布局；
  - `ui-spec.md`：Design Tokens（颜色、阴影、圆角、字号）、组件状态（Default, Hover, Active, Disabled, Loading）与响应式适配；
- **设计还原度循环验收（UI Walkthrough Loop）**：
  - 在全栈开发提交前端组件或页面后，主动进行像素级与交互走查；
  - 对照 UI Spec 记录偏差列表（间距、色值、动效、异常态反馈），生成走查缺陷清单发回开发；
  - 与开发保持双向通信，直至所有视觉与交互体验缺陷闭环清零。

## 3. 交付契约与规范
- 交付物输出至 `team-deliverables/design/`；
- 设计规范需结合工程实际，避免不可落地的伪交互设计。
