## 1. 产品概述

### 1.1 产品定位

LibreTV（cl.tv）是一款现代化全维流媒体视听与 IPTV 聚合平台，基于 **元数据中心化 + JIT（即时）多源切片流匹配** 的双层解耦架构，为用户提供极致纯净、无任何商业广告、注重个人隐私的高清观影体验。

产品本身**不内置任何影视内容、电视频道或第三方商业账号**，仅提供第三方公开接口的聚合与播放能力。

### 1.2 核心架构

```
┌─────────────────────────────────────────────────────────────┐
│              全球权威影视元数据库 (Metadata Core)            │
│   (官方标准剧名 · 4K/高清海报 · 权威演职员名录 · 真实评分)    │
└──────────────────────────────┬──────────────────────────────┘
                               │
                    用户发起「搜索 / 探索片库 / 浏览热榜」
                               ▼
┌─────────────────────────────────────────────────────────────┐
│              高颜值纯净卡片网格与官方影视档案                 │
│            (毫秒级响应 · 杜绝牛皮癣广告 · 视觉统一)           │
└──────────────────────────────┬──────────────────────────────┘
                               │
                        用户点击「立即播放」
                               ▼
┌─────────────────────────────────────────────────────────────┐
│            JIT 即时切片流匹配引擎 (Playback Engine)           │
│   (数十条全球专线毫秒级并发测速 · 自动对齐集数 · 秒播起播)    │
│                · 智能动态故障转移 (Auto Failover)            │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 核心原则

1. **元数据中心化**：首页、搜索、片库、详情统一由权威影视资料库驱动，告别低质水印与广告。
2. **JIT 多源切片流匹配**：搜索与浏览与播放源完全解耦，点击播放瞬间并发测速选优，支持自动故障转移。
3. **本地优先与纯隐私保护**：搜索历史、收藏夹、播放进度 100% 留存在用户设备 IndexedDB 中，无需注册，绝不上传云端。
4. **无商业广告**：全站不出现插屏、贴片广告、弹窗广告；仅保留功能性提示（加载中、空状态、错误）。
5. **端到端安全**：服务端内置严格 SSRF 校验（内网与保留地址阻断）与速率限制。

## 2. 目标用户

| 用户角色 | 特征 | 核心诉求 |
|---------|------|---------|
| **影视爱好者** | 追求高清画质、官方译名、真实评分，厌恶广告和水印 | 快速找到想看的内容，秒播高清流，无广告打扰 |
| **追剧用户** | 关注剧集更新、集数进度、续播体验 | 收藏追剧，自动同步最新集数，断点续播 |
| **IPTV/直播用户** | 需要 M3U 播放列表与 XMLTV EPG 支持 | 订阅直播源，频道收藏，节目单查询 |
| **隐私敏感用户** | 不愿注册账号，数据不愿上传云端 | 本地存储，无账号体系，纯隐私保护 |
| **技术爱好者/自建用户** | 自建内网 IPTV、自定义数据源、订阅同步 | 添加自定义源、订阅同步、配置导入导出、内网代理 |

### 2.2 非目标用户（Won't）

- 需要云端同步观看历史/收藏/设置的跨设备用户（本版本为本地优先，无云同步）
- 需要评论、弹幕、社区互动的用户
- 需要付费会员、支付订阅的用户
- 需要管理后台页面的运营人员（当前 admin 能力仅通过 API 提供）

## 3. 核心功能模块

本版本覆盖 6 个页面模块，优先级定义：

| 优先级 | 定义 |
|--------|------|
| **Must** | 核心流程，必须实现，直接影响观影体验，无法缺失 |

## 5. 关键业务流程

### 5.1 观影主流程

```
用户打开首页
    │
    ▼
[Hero 轮播 / 推荐卡片 / 热播榜] ──► 点击卡片
    │                                   │
    │                                   ▼
    │                          [登录态校验]
    │                                   │
    │                  未登录 ──► [跳转 /login?redirect=/watch?...]
    │                                   │ 登录成功
    │                                   ▼
    │                          [回跳 /watch?source=...&id=...&index=...]
    │                                   │
    ▼                                   ▼
[搜索框] ──► [官方搜索 TMDB] ──► [结果卡片] ──► 点击卡片 ──► [播放页]
                                  │
                                  └─► [底层采集源深度扫描] ──► [聚合卡片] ──► 点击卡片 ──► [播放页]
```

播放页内部：
```
[播放页打开] ──► [拉取详情] ──► [多源并发测速] ──► [选优线路开始播放]
                                    │
                                    ├─► [播放中线路异常] ──► [自动故障转移 + toast 提示]
                                    ├─► [点击切换线路] ──► [保留进度，切换源继续播放]
                                    ├─► [点击集数] ──► [URL index 更新，新集加载，不刷新]
                                    ├─► [点击追剧单星标] ──► [加入/移出，首页红点同步]
                                    └─► [播放进度持久化到 IndexedDB]
```

### 5.2 搜索融合展示流程

```
[搜索框输入关键词]
    │
    ├─► [官方 TMDB 搜索，≤2s 返回卡片网格] ──► [优先展示官方高清卡片]
    │
    └─► [底层采集源并发搜索，NDJSON 流式推送] ──► [按源分组聚合卡片，折叠展开]
                                          │
                                          └─► [坏源琥珀色标记，不阻塞好源]
```

### 5.3 图片加载优化流程

```
[页面加载]
    │
    ├─► [Hero 当前图片 loading='eager'，立即加载] ──► [骨架屏兜底] ──► [≤3s 完成 LCP]
    │
    ├─► [首屏卡片海报 loading='eager'] ──► [骨架屏 + 平滑淡入]
    │
    └─► [非首屏图片 loading='lazy' + IntersectionObserver(200px)] ──► [进入视口附近才加载]
    
[图片加载模式] ──► [遵循 store.imageProxyMode / /api/status defaultImageMode: direct/proxy/custom]
[图片加载失败] ──► [所有候选链耗尽] ──► [兜底占位 + 抖动提示，不展示破损图标]
```

### 5.4 登录拦截与回跳流程

```
[未登录访问 /watch 或点击播放入口]
    │
    ▼
[跳转 /login?redirect=<当前完整 URL>]
    │
    ├─► [账号登录 / 邀请码注册] ──► [登录成功]
    │                                   │
    │                                   ▼
    │                          [window.location.href = redirect 回跳]
    │
    └─► [已登录用户访问 /login] ──► [自动跳回首页或 redirect]
```

## 7. 约束与边界

### 7.1 技术约束

1. **无新增后端**：本版本全部基于现有 API/lib 能力，无需新增后端接口。
2. **Node 22**：与 Docker 及 CI 保持一致，`npm ci` 安装依赖。
3. **本地优先**：搜索历史、收藏、播放进度、设置均存储在浏览器本地（IndexedDB/localStorage），无云端同步。
4. **无商业广告**：全站不插入任何商业广告。
5. **SSRF 防护**：所有服务端外部请求必须经过 `checkUpstreamAllowed` 校验，严禁请求内网私有地址（`127.0.0.1`、`10.0.0.0/8`、`192.168.0.0/16`、`172.16.0.0/12`）。
6. **图片代理限制**：未登录仅放行白名单图片域（豆瓣、bgm.tv、qhimg.com、bdstatic.com）；已登录受 SSRF 防护。
7. **分类 ID 跨源不统一**：采集站分类 `type_id` 在各站间完全不同，只能按分类名匹配，不能依赖固定 ID。
8. **Master 分支红线**：严禁直接 Push 到 Master，必须通过 PR 与 CI 门禁。

### 7.2 业务边界

| 边界项 | 说明 |
|--------|------|
| 内容版权 | 本项目不存储、不制作任何视频内容，内容合法性由对应数据源负责 |
| 用户账号 | 仅站点访问认证密码（PASSWORD），无个人资料、昵称、头像、邮箱 |
| 云同步 | 无云端同步，数据 100% 本地存储 |
| 付费支付 | 无付费会员、支付、订阅会员体系 |
| 管理后台 | 当前 admin 能力仅通过 API 提供，无前端管理页面 |
| 评论弹幕 | 无评论、弹幕、评分、社区互动 |
| 推送通知 | 无 WebSocket 推送、订阅剧集更新通知 |

### 7.3 性能指标（P0 验收）

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 首屏 LCP 图片加载时间 | ≤ 3s（4G/WiFi） | 页面性能监控 |
| 图片加载失败率 | ≤ 1% | 所有候选链耗尽后展示兜底占位 |
| 骨架屏覆盖率 | 100%（所有首屏海报位） | UI 检查 |
| TMDB 官方搜索结果出现 | ≤ 2s | 搜索接口响应时间 |
| 播放页自动故障转移 | ≤ 5s 切换至备用线路 | 播放中断后切换耗时 |
| 源切换后播放启动 | ≤ 2s | 点击切换源后新源开始播放 |
| 断点续播误差 | < 2 秒 | 刷新后从上次停留位置续播 |
| 100 集选集滚动帧率 | 60fps | 性能测试 |
| DOM 节点增长 | 不随集数线性增长 | 虚拟滚动检查 |

## 8. 验收标准（QA 可直接使用）

### 8.1 首页（`/`）

1. 打开首页，Hero 轮播在 3 秒内加载并显示 6 部官方趋势大片，当前图片使用 `loading='eager'`。
2. Hero 图片加载期间显示骨架屏，非空白占位。
3. 输入有效关键词，TMDB 官方搜索结果在 2 秒内出现卡片网格。
4. 展开“底层采集源深度扫描”后，各源结果逐条流式出现，坏源不阻塞好源。
5. 未登录用户点击任意卡片播放，跳转 `/login?redirect=/watch?...`，登录成功后回跳播放页。
6. 成人过滤开启时，搜索结果中不包含标记为 `isAdult` 的源结果。
7. 搜索框聚焦时展示搜索历史与热词，点击历史词/热词直接执行搜索。
8. 首屏图片加载失败时，显示兜底占位 + 抖动提示，不展示破损图标。
9. 非首屏图片使用 `loading='lazy'`，仅在进入视口附近 200px 时加载。

### 8.2 片库页（`/catalog`）

1. 切换频道，页面标题、副标题、图标、可用筛选维度随频道变化。
2. 选择地区/类型/年份后，片库卡片列表重新加载并反映筛选条件。
3. 输入关键词并点击“深搜”，显示“正在【频道】全库深度搜索”横幅与结果计数。
4. 分页点击后，URL 更新并保持筛选条件，刷新页签不丢失筛选状态。
5. 未登录用户点击卡片，跳转登录页并携带 redirect 参数。
6. 热门搜索词点击后填入搜索框并自动触发搜索。

### 8.3 播放页（`/watch`）

1. 播放页打开后，自动拉取详情并开始播放首集；若当前源无播放地址，显示“立即切换至备用线路”按钮。
2. 多源测速面板显示各源名称、延迟、QoS 等级，点击任意源立即切换并继续播放。
3. 播放中若当前线路异常，自动在 5 秒内切换至下一条高速线路，不中断观看，并出现 toast 提示。
4. 切换集数后，URL 参数 `index` 更新，页面不刷新，新集自动加载。
5. 点击“加入追剧单”后，星标变为填充状态；该剧有新集时首页出现红点提醒。
6. 刷新播放页后，视频从上次停留位置续播（误差 < 2 秒）。
7. 点击“跨屏接力”生成二维码，扫码后在另一设备打开对应 URL 从相同时间点续播。
8. 点击“下载本集”进入下载队列，支持 MP4 格式。
9. 未登录用户直接访问 `/watch`，跳转 `/login?redirect=/watch?...`。
10. 100 集以上选集滚动无卡顿（60fps），DOM 节点数不随集数线性增长。
11. 选集支持“百集分段折叠”，当前集高亮，切换集数 URL `index` 参数更新且不刷新页面。
12. 所有候选源不可用时，显示兜底状态与“立即切换至备用线路”手动入口。

### 8.4 历史页（`/history`）

1. 历史页按时间倒序显示最近 50 条记录，超出部分可通过搜索查找。
2. 每条记录显示进度条（观看进度 >10% 且 <95% 时显示百分比）。
3. 搜索关键词后，列表实时过滤匹配标题的记录。
4. 点击“删除”单条记录，出现“已删除”提示并提供 5 秒“撤销”入口，撤销后记录恢复。
5. 点击“清空历史”并确认后，全部记录删除，显示“暂无观看记录”。
6. 点击任意记录，跳转 `/watch?source=...&id=...&index=...` 并从上次进度续播。

### 8.5 登录页（`/login`）

1. 未设置 PASSWORD 时，访问任何页提示管理员配置密码。
2. 输入正确账号密码，登录成功后跳转 redirect 参数指定的页或首页。
3. 输入错误密码，显示“登录失败，请检查账号密码”错误条。
4. 注册时邀请码为空、账号<3 字符、密码<6 字符、两次密码不一致，分别给出对应校验提示。
5. 注册成功后自动登录并跳转。
6. 已登录用户访问 `/login`，自动跳回首页。

### 8.6 设置页（`/settings`）

1. 添加自定义点播源后，源出现在点播源列表并可勾选参与搜索。
2. 添加订阅 URL 并点击同步，订阅下的点播源与直播源批量导入，同步结果显示数量与状态。
3. 开启成人内容过滤后，已勾选的成人源自动取消勾选，搜索中不再出现。
4. 切换封面图加载模式为“代理”，全站封面图走服务端代理，不直接请求上游。
5. 点击“导出配置”下载 JSON 文件；在另一设备导入同一文件，设置与源列表恢复一致。
6. 删除源后出现撤销提示，5 秒内点击撤销可恢复。

### 8.7 全局

1. 全站无商业广告（插屏、贴片、弹窗）。
2. 深色/浅色主题切换正常。
3. 移动端底部标签栏与桌面端顶部导航均可正常使用。
4. 未登录访问受保护页统一跳转 `/login?redirect=`，登录后回跳。
5. 所有测试必须通过，不允许存在失败或 `.skip` 用例。
