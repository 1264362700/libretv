> **说明**：本文档以文字 + ASCII 线框的形式表达低保真原型。所有页面均采用深色主题为主（`bg-page`），支持浅色/深色切换；无商业广告，仅保留功能性提示（加载中、空状态、错误）。

## 0. 全局状态组件规范（所有页面共用）

### 0.1 加载态（Loading）

| 组件 | 尺寸 | 使用场景 | 视觉 |
|------|------|----------|------|
| `Spinner` | sm | 按钮内加载（如登录按钮、添加源按钮） | 中心居中旋转 |
| `Spinner` | md | 搜索加载、详情加载 | 区块居中 |
| `Spinner` | lg | 播放器加载、页面初屏加载 | 区块居中，大尺寸 |
| `CatalogSkeleton` | — | 片库页列表加载 | 与真实卡片 1:1 几何对齐，`bg-slate-800/20` + `animate-pulse` |
| `SmartImage` 骨架屏 | — | 所有海报位加载前 | 固定 aspect-ratio，`bg-slate-800/20`，不留空白 |

### 0.2 空态（Empty State）

```
┌─────────────────────────────────────┐
│    [图标，如 🍿 / 📭 / 🔍]          │
│                                     │
│    标题：暂无内容                   │
│    描述：一段简短说明（1-2 行）      │
│                                     │
│    [可选：操作按钮，如“尝试深度搜索”]│
└─────────────────────────────────────┘
```

使用场景：
- 首页：未搜到匹配影视 → 提供“尝试通过底层采集源深度直搜”入口
- 片库页：频道下无影片或搜索无结果 → “尝试清空筛选条件”按钮
- 历史页：暂无观看记录
- 播放页：无可用播放源 → “立即切换至备用线路”

### 0.3 错误态（Error State）

```
┌─────────────────────────────────────┐
│  ⚠  加载失败 / 播放失败              │
│                                     │
│  一段简短错误说明                   │
│                                     │
│  [重试按钮]  [切换源按钮]           │
└─────────────────────────────────────┘
```

- 图片加载所有候选链耗尽后：显示“封面加载失败”占位图，带轻微抖动提示（`FAILED_SHAKE_CLASS`），`aria-label` 说明失败原因；不影响卡片点击播放。
- 播放器无播放地址：显示错误 + “立即切换至备用线路”按钮。
- 登录失败：显示“登录失败，请检查账号密码”错误条（danger 类型）。

### 0.4 成功态（Success State）

```
┌─────────────────────────────────────┐
│  ✓  操作成功                        │
│                                     │
│  一段简短成功说明                   │
│  （如“已加入追剧单”、“配置已导出”）  │
└─────────────────────────────────────┘
```

- 采用 Toast 顶部/右下角轻提示，支持 success/info/danger 类型，可带操作按钮（如“撤销”）。
- 追剧单切换：星标变为填充状态，toast 提示，首页红点同步。

### 1.1 关键交互

| 交互点 | 触发方式 | 行为 |
|--------|----------|------|
| 搜索框输入 | 输入关键词，回车或失焦 | 跳转 `/catalog?wd=<关键词>` 或在首页内展示搜索结果区 |

| 登录状态变更 | 未登录访问受保护能力 | 弹出登录框或跳转登录页，携带 redirect |

| 交互点 | 触发方式 | 行为 |

| 自动连播 | 勾选复选框 | 播放结束后自动加载下一集 |

### 4.1 删除/撤销流程

```
删除单条：
[🗑 点击删除] → 记录移除 → toast“已删除” + 5 秒 [撤销] 入口 → 撤销后记录恢复

清空历史：
[清空历史] → ConfirmDialog“清空全部观看历史？将删除 N 条记录，此操作不可撤销。”
  → [取消] / [清空] → 全部删除 → 显示空态“暂无观看记录”
```

### 4.2 关键交互

| 交互点 | 触发方式 | 行为 |
|--------|----------|------|
| 历史记录点击 | 点击列表项 | 跳转 `/watch?source=...&id=...&index=...&position=...`，恢复进度 |
| 搜索过滤 | 输入关键词 | 列表实时过滤匹配标题的记录 |
| 删除单条 | 点击条目右侧删除图标 | 记录移除，toast 显示“已删除”并提供 5 秒“撤销”入口 |
| 清空历史 | 点击“清空历史”按钮 | 弹出确认对话框，确认后全部删除，显示空态 |
| 撤销删除 | toast 中点击“撤销” | 恢复被删除的记录 |

| 已登录访问 | 检测到 `verified=true` | 自动跳转 redirect 或首页 |
| 返回首页 | 点击底部链接 | 跳转 `/` |
