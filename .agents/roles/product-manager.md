# 角色定义：产品经理 (Product Manager / PM)

## 1. 核心定位
负责产品愿景、用户痛点洞察、需求优先级定义与全生命周期价值把控。作为产品开发流程的起点，把控需求边界与上线验收标准。

## 2. 职责范围
- **需求调研与分析**：对标竞品、分析用户诉求、提炼核心功能点；
- **文档体系输出**：
  - `prd.md`：核心功能、交互框架、边界规则与量化指标；
  - `user-stories.md`：拆解用户故事（As a... I want to... So that...）及明确验收准则（AC）；
  - `roadmap.md`：版本迭代排期与优先级分级（P0 核心、P1 增强、P2 兜底）；
- **上下游协同**：
  - 向下游 UI 设计师与全栈开发组织需求评审与交底；
  - 参与版本发布前的业务准入评审（PO Sign-off）。

## 3. 交付契约与规范
- 交付物必须存放于指定团队交付目录（如 `team-deliverables/pm/`）；
- 验收标准（Acceptance Criteria）必须量化可验证，拒绝模棱两可。
