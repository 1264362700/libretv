# LibreTV / cl.tv 用户故事与验收标准

**版本**：v1.1  
**基准**：PRD v1.1（整合主 PRD + 图片优化 + 下一版迭代）  
**产品**：LibreTV（cl.tv）视频聚合播放平台  
**适用对象**：QA 测试工程师（直接用于制定测试计划与测试用例）、全栈开发者、UI/UX 设计师  
**生效日期**：2026-11-04  
**状态**：草稿，待 Lead 确认后冻结  

---

## 1. 使用说明

本文档采用标准用户故事格式：

> 作为 <角色>，我想要 <目标>，以便 <价值>。

每个用户故事下列出 **验收标准（Acceptance Criteria）**，以 `AC-` 编号。验收标准采用 **Given / When / Then** 格式，QA 可直接据此编写测试用例，每条验收标准对应一个或多个测试用例。

验收标准优先级与 PRD 中的 MoSCoW 一致：
- **Must**：核心流程，必须 100% 通过
- **Should**：重要增强，应通过
- **Could**：可选，资源允许时通过
- **Won't**：本版本明确不纳入

## 2. 用户角色

| 角色代号 | 角色名称 | 特征 |
|----------|----------|------|
| R1 | 普通观众 | 未登录或已登录，追求高清、无广告、秒播 |
| R2 | 追剧用户 | 关注剧集更新、集数进度、断点续播、追剧单 |
| R3 | 隐私敏感用户 | 不愿注册，数据本地化，无云同步 |
| R4 | 技术/自建用户 | 自定义数据源、订阅同步、配置导入导出、内网 IPTV |
| R5 | 管理员/部署者 | 设置 PASSWORD、预置数据源、配置图片模式 |

## 3. 用户故事清单

### 3.1 首页（`/`）

#### US-001：观看 Hero 趋势大片轮播

**作为** 普通观众（R1），**我想要** 在首页看到 Hero 巨幕轮播的官方 4K 趋势大片，**以便** 快速发现热门内容并点击播放。

**优先级**：Must

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-001.1 | Given 用户打开首页 `/`；When 页面加载完成；Then Hero 轮播在 3 秒内显示 6 部官方趋势大片，每张带标题、评分、年份、播放按钮 |
| AC-001.2 | Given Hero 图片加载中；Then 显示骨架屏占位，不展示纯空白 |
| AC-001.3 | Given Hero 当前可见图片；Then 使用 `loading='eager'` 立即加载，不延迟到 JS 执行后 |
| AC-001.4 | Given Hero 轮播切换时；Then 下一张图片预加载，切换无空白闪烁 |
| AC-001.5 | Given 所有图片候选链加载失败；Then 显示兜底占位 + 抖动提示，不展示破损图标 |

#### US-002：官方精准搜索

**作为** 普通观众（R1），**我想要** 输入关键词在 TMDB 官方资料库搜索，**以便** 获得标准海报、正规剧名、真实评分、年份。

**优先级**：Must

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-002.1 | Given 用户输入有效关键词并提交；When 调用 TMDB 官方搜索；Then 2 秒内返回卡片网格，显示标准海报、正规剧名、真实评分、年份 |
| AC-002.2 | Given 搜索关键词长度；Then 长度 ≤ 100 字符 |
| AC-002.3 | Given 搜索无结果；Then 显示空态 EmptyState，并给出“尝试通过底层采集源深度直搜”入口 |

#### US-003：底层采集源深度扫描

**作为** 普通观众（R1），**我想要** 展开底层采集源深度扫描，**以便** 看到多源并发搜索结果，坏源不阻塞好源。

**优先级**：Must

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-003.1 | Given 用户点击“展开底层采集源深度扫描”；When 多源并发搜索；Then 各源结果逐条流式出现（NDJSON），坏源不阻塞好源展示 |
| AC-003.2 | Given 某源搜索超时或失败；Then 该源以琥珀色标记，不影响其他源结果 |

#### US-004：首屏图片加载优化

**作为** 普通观众（R1），**我想要** 首页图片快速加载且布局稳定，**以便** 减少等待和页面抖动。

**优先级**：Must

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-004.1 | Given 首屏 Hero 当前图片；Then LCP 图片加载时间 ≤ 3s（4G/WiFi 下） |
| AC-004.2 | Given 首屏可见卡片海报；Then 使用 `loading='eager'` 优先加载，加载期间显示骨架屏 |
| AC-004.3 | Given 图片加载完成后；Then 以 `opacity-0 → opacity-100` 平滑淡入（duration-300） |
| AC-004.4 | Given 非首屏图片；Then 使用 `loading='lazy'` + IntersectionObserver（rootMargin 200px），仅在进入视口附近时加载 |
| AC-004.5 | Given 所有海报位；Then 固定 `aspect-ratio`，图片加载前后布局不抖动（CLS ≈ 0） |
| AC-004.6 | Given 图片加载失败率；Then ≤ 1%，失败后展示兜底占位，不影响卡片点击进入播放页 |
| AC-004.7 | Given 图片加载模式；Then 遵循用户设置 `store.imageProxyMode` 与部署者默认值 `/api/status` `defaultImageMode`（direct/proxy/custom） |

#### US-005：搜索历史与热词

**作为** 普通观众（R1），**我想要** 搜索框聚焦时看到搜索历史与热词，**以便** 快速再搜或点击热词搜索。

**优先级**：Should

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-005.1 | Given 搜索框聚焦；When 无搜索关键词；Then 显示搜索历史列表（本地 IndexedDB/localStorage，非云端）与频道热词 |
| AC-005.2 | Given 点击历史搜索词；Then 直接执行该关键词搜索 |
| AC-005.3 | Given 点击热门搜索词；Then 填入搜索框并自动触发搜索 |
| AC-005.4 | Given 每频道热词；Then 展示 5–8 个热词，以药丸按钮形式展示 |

#### US-006：官方搜索与底层源融合展示

**作为** 普通观众（R1），**我想要** 官方高清卡片优先展示，底层源结果作为折叠展开，**以便** 统一入口获取内容。

**优先级**：Should

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-006.1 | Given 同一搜索词；When 官方 TMDB 搜索与底层源搜索并行；Then 官方高清卡片优先展示，底层源结果作为「底层采集源深度扫描」折叠展开 |
| AC-006.2 | Given 底层源结果；Then 按源分组聚合卡片，显示源名称、年份、地区、备注 |

#### US-007：源选择与成人过滤

**作为** 普通观众（R1），**我想要** 勾选参与搜索的源并开启成人过滤，**以便** 控制搜索范围和内容过滤。

**优先级**：Should

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-007.1 | Given 用户在设置页勾选参与搜索的源；When 搜索；Then 仅选中源参与搜索 |
| AC-007.2 | Given 成人过滤开启；When 搜索；Then 结果中不包含标记为 `isAdult` 的源结果 |

#### US-008：登录拦截与回跳

**作为** 未登录用户（R1/R3），**我想要** 点击播放时被引导登录，**以便** 获得播放权限。

**优先级**：Must

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-008.1 | Given 未登录用户点击任意卡片播放；When 触发播放入口；Then 跳转 `/login?redirect=/watch?...`，携带完整当前 URL |
| AC-008.2 | Given 登录成功后；When 回跳；Then `window.location.href = redirect` 回到播放页 |
| AC-008.3 | Given 已登录用户访问 `/login`；Then 自动跳回首页或 redirect |

#### US-015：视频播放

| AC-015.2 | Given 播放器；Then 支持 HLS / HTTP-FLV，0.5x~3.0x 倍速，键盘快捷键（空格播放/暂停，←/→ 快退/快进 5 秒，↑/↓ 音量，F 全屏，Alt+←/→ 切换集数） |

| AC-015.4 | Given 影院宽屏模式；Then 收起右侧选集栏，视区扩大 |

#### US-016：多源测速可视化

**作为** 普通观众（R1），**我想要** 看到各候选源的测速结果与 QoS 等级，**以便** 感知多源选优价值并手动切换。

**优先级**：Should

**验收标准**：

| ID | Given / When / Then |
|----|---------------------|
| AC-016.1 | Given 播放页测速面板；Then 显示各候选源名称、实时延迟 ms 与 QoS 等级徽章：绿色（< 500ms 极速）、琥珀色（500~1500ms 可用）、红色（> 1500ms 迟钝），并标记当前播放源与受阻线路 |
| AC-016.2 | Given 测速进行中；When 并发探测多源；Then 单源硬超时设为 3000ms 自动截断，显示检测进度条（已检测/总数），坏源不阻塞健康源秒级渲染与起播 |
| AC-016.3 | Given 点击任意候选源；When 立即切换；Then 2 秒内新源开始播放，保留当前播放进度（误差 ≤ 2 秒） |
| AC-016.4 | Given 检测到更快线路；When 弹出速度建议弹窗；Then 显示当前源 vs 目标源延迟对比，点击接受后切换源 |

#### US-017：自动故障转移与状态反馈

**作为** 追剧用户（R2），**我想要** 播放中线路异常时自动切换备用线路并提示，**以便** 观看不中断。

| AC-017.2 | Given 所有候选源均不可用；When 播放失败；Then 显示兜底状态与“立即切换至备用线路”手动入口 |
| AC-017.3 | Given 源被自动停用（连续失败/超时）；When 线路栏展示；Then 该源显示“受阻”或灰色不可点，琥珀色区分超时 vs 失败 |

## 5. 测试类型与覆盖要求

| 测试类型 | 覆盖场景 | 验收点 |

| 安全测试 | SSRF 校验、内网地址阻断、未登录图片代理白名单 | 安全红线不突破 |

## 6. 缺陷等级定义

| 等级 | 定义 | 处理时限 |
|------|------|----------|
| P0（阻塞） | Must 验收标准失败，核心流程不可用（如无法播放、无法登录、首屏空白） | 上线前必须修复 |
| P1（严重） | Should 验收标准失败，重要功能异常（如测速面板不显示、追剧单不生效） | 上线前修复或顺延至下一版本 |
| P2（一般） | Could 验收标准失败，可选功能异常 | 下一版本候选 |
| P3（提示） | UI 文案、轻微布局问题，不影响功能 | 可选修复 |
