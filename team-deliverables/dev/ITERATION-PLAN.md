## 2. 下一版迭代主题

建议聚焦 **2 个核心主题**，按优先级排序：

### 主题一：播放页体验提升（核心，P0–P1）

播放是产品的核心价值交付点。当前已有多源并发测速、自动故障转移、选集、追剧单等能力，但体验层可进一步打磨：

- **多源测速可视化**：将测速过程、各源延迟、QoS 等级以可视化面板呈现，让用户感知「多源测速选优」的价值，而非仅在按钮后黑盒执行。
- **故障转移状态反馈**：当自动切换线路时，给予明确的状态提示（哪条线路不可用、切换到哪条、当前延迟），降低用户困惑。
- **选集滚动性能**：百集以上长剧的选集列表，当前未充分使用虚拟滚动，滚动卡顿会影响体验。

### 主题二：搜索体验（重要，P1）

内容发现是留存的前置。当前官方搜索（TMDB）与底层源搜索（采集站）展示较为割裂，且缺乏搜索历史与热词沉淀：

- **官方搜索与底层源搜索融合展示**：同一搜索词下，官方高清卡片优先展示，底层源结果作为「更多播放源」折叠展开，统一入口。
- **搜索历史**：已有 `search-history.tsx` 组件，可将其接入首页/片库页搜索入口，支持点击历史快速再搜。
- **热词与最近搜索**：基于已有 `CHANNEL_HOT_KEYWORDS` 与搜索历史，在搜索聚焦时展示热词推荐，降低输入成本。

## 4. 页面与路由规划

### 4.1 涉及现有页面

| 页面 | 路由 | 是否变更 | 变更说明 |
|------|------|----------|----------|
| 首页 | `/` | 是 | 搜索入口接入搜索历史与热词；官方搜索与底层源融合展示 |
| 片库页 | `/catalog` | 是 | 搜索入口接入搜索历史与热词；筛选防抖（可选） |
| 播放页 | `/watch` | 是 | 测速可视化、故障转移状态反馈、选集虚拟滚动 |
| 历史页 | `/history` | 否 | 无变更 |
| 登录页 | `/login` | 否 | 无变更 |
| 设置页 | `/settings` | 否 | 无变更（本版不涉及） |

### 4.2 是否需要新增页面路由

**否。** 本版迭代全部在现有页面内完成，无需新增路由。所有交互通过现有路由的查询参数（`?wd=`、`?source=`、`?id=`、`?index=`）与组件内状态完成。

### 4.3 路由跳转关系变化

```
[首页 /] ──搜索──► [片库页 /catalog?wd=...] ──点击卡片──► [播放页 /watch?...]
   │                                                    │
   └──点击播放──────────────────────────────────────────┘
                                                    │
                                                    ▼
                                              [登录页 /login?redirect=/watch?...]
```

变更点：
- 首页/片库页搜索框聚焦后，弹出搜索历史与热词面板（非路由跳转，组件内状态）。
- 点击历史词/热词，直接在当前页执行搜索（URL 参数 `wd` 更新，不新增路由）。
- 播放页测速面板与故障转移提示均为组件内弹层/ toast，不新增路由。

## 6. 风险与依赖

### 6.1 需要后端配合的模块

| 模块 | 风险说明 | 应对 |
|------|----------|------|
| 无 | 本版全部基于现有 API/lib 能力，无需新增后端接口 | 否 |

### 6.2 第三方依赖风险

| 风险项 | 说明 | 应对 |
|--------|------|------|
| 图片源跨国延迟 | 官方 TMDB 海报、底层源海报均依赖第三方图片源，首屏加载仍可能受网络影响 | 复用首页图片优化成果（代理模式、骨架屏、懒加载）；搜索结果页同样启用 `SmartImage` |
| Render 实例网络限制 | 线上站点部署在 Render，服务端代理请求上游可能受限 | 搜索与详情请求设置合理超时；服务端缓存（`searchCacheKey` 90s、`detail` 60s）已有，继续沿用 |
| 第三方源不稳定 | 采集站搜索/详情接口可能返回 HTML 错误页或超时 | 已有 SSRF 校验、JSON 格式校验、容错降级、超时隔离；前端展示失败兜底 |

### 6.3 测试覆盖要求

| 测试类型 | 覆盖场景 | 验收点 |
|----------|----------|--------|
| 功能测试 | 测速面板显示、源切换、故障转移 toast、选集切换、搜索融合展示、搜索历史/热词 | 所有 P0/P1 验收标准 100% 通过 |
| 性能测试 | 100 集选集滚动帧率、测速面板渲染时间、搜索结果首屏时间 | 选集滚动 60fps；搜索官方结果 ≤ 2s 出现 |
| 兼容测试 | 桌面端（Chrome/Edge/Safari）、移动端（iOS Safari/Android Chrome） | 移动端搜索面板与底栏导航不冲突；播放页横竖屏正常 |
| 异常测试 | 所有播放源不可用、搜索源全部超时、图片加载失败 | 兜底 UI 正常显示；无页面崩溃 |
| 回归测试 | 首页图片优化已上线功能不受影响 | 图片骨架屏、懒加载、代理模式正常 |
